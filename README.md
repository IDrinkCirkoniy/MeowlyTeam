# MEOWLY
## проект для 3 лабы
Нужен чтобы продемонстрировать работу в одном репозитории
## Установка
Инструкции по установке:
bash
git clone <URL-репозитория> cd <имя_проекта>
dotnet build
## Использование
bash dotnet run
## Системные требования
1. .NET 10.0 или выше
2. MS SQL
3. Windows 11 и выше
## Контрибьютинг
Особых требований нет
## Лицензия
Бесплатно для всех CC
